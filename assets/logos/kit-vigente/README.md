# Kit de logo vigente — Meridiano Capital + Urbannit

Generado 2026-11-12 desde los SVG de produccion (`production/app/frontend/assets/logos/`).
Construccion vigente: mojon "partido por el meridiano" (D-034), cerradura en trazo abierto (D-035), wordmark Fraunces (D-036).

**Diferencia con los SVG de produccion:** aca el wordmark esta **convertido a curvas** (Fraunces wght 600 / opsz 80 / SOFT 24 / WONK 0; Poppins Bold para Urbannit). No depende de que la fuente este instalada — ChatGPT, Canva, PowerPoint o un editor de video lo muestran igual. Los PNG son transparentes (isotipo 1200 px, horizontal 2400 px de ancho).

| Archivo | Uso |
|---|---|
| `meridiano-horizontal-claro` | Fondo crema/blanco — uso por defecto (portadas, documentos) |
| `meridiano-horizontal-inverso` | Fondo petroleo #14313A o tierra colorada #8B3323 (portada oscura, cierre) |
| `meridiano-isotipo-claro` | Esquina de diapositivas de contenido, marca de agua, avatar, < 32 px |
| `meridiano-isotipo-inverso` | Lo mismo sobre fondo oscuro; apertura/cierre de video |
| `urbannit-horizontal` / `urbannit-isotipo` | Solo piezas de Urbannit (fondo arena/blanco). Nunca junto a la paleta de Meridiano |

No incluidos (no definidos todavia para la construccion D-034, no inventar): version apilada/vertical y version monocromatica. Si se necesitan, pedirlas como [EXTENSION].

`hoja-de-prueba.png` muestra cada archivo sobre sus fondos permitidos.
