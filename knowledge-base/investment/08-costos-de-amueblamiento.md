# Costos de amueblamiento por tipología y calidad

**Uso**: costo de referencia para amueblar una unidad, por tipología y nivel de calidad — cross-cutting, no específico de un caso. Primer caso que la usa: `contracts/cases/HERRERA-001/` (ver `09-comision-con-iva-plazo-obra-vehiculo-legal-amoblamiento-y-verificacion-de-costos.md` §4 y `23-amueblamiento-en-plusvalia-y-rentabilidad-zona-y-calidad.md`).

## Regla de aplicación — se suma en DOS cálculos, no solo uno (ampliado 2026-08-16)

*"Tanto para calcular la plusvalía como la rentabilidad del alquiler, siempre verificar que si el departamento se alquila y/o se vende amoblado, debemos sumar los costos del amueblamiento para dichos cálculos."*

> **Siempre que una unidad se alquile y/o se venda amoblada, el costo de amueblamiento se suma a la base de cálculo — tanto para la rentabilidad de alquiler como para la plusvalía.**

- **Rentabilidad de alquiler**: costo de entrada de la unidad (construcción/adquisición) + costo de amueblamiento → base sobre la que se aplica el piso de rentabilidad de la clase (`03-parametros-de-mercado.md`).
- **Plusvalía**: precio de venta de referencia (hoy y en el futuro) + costo de amueblamiento, si la unidad se vende amoblada → base sobre la que se aplica el piso de plusvalía (nuevo criterio, ver `05-matriz-pisos-techos.md`/case files de referencia).

## Calidad de amueblamiento según la zona (nuevo, 2026-08-16)

*"Es sumamente importante tener nuestra planilla de barrios de Asunción bien categorizada, porque nos va a permitir tomar, entre otras cosas, decisiones para la calidad del amueblamiento según la zona."*

La calidad de amueblamiento a usar (Básico/Estándar/Premium/Lujo) se decide en función de la categoría y el posicionamiento de la zona (ver `07-tarifas-por-barrio-asuncion.md`), no de forma aislada por unidad — una zona premium (alto precio/m², alta demanda confirmada) justifica amueblamiento de mayor calidad; una zona más modesta no lo justifica económicamente. Todavía no hay una tabla cerrada "zona → calidad" — depende de que se confirmen las "zonas definitivas" del ranking de `07-...md`.
