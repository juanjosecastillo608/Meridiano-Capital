# Sistema Grafico

**Estado: [EXTENSION].** El Brand Guidelines v1.0 no desarrollo un capitulo dedicado de grafismos/patrones/iconografia extendida — este modulo se construye por extension directa y coherente de Identidad Visual (`03-identidad-visual.md`) y Sistema Cromatico (`05-sistema-cromatico.md`), que si son oficiales. Tratar las reglas de este archivo como recomendaciones aplicadas del sistema, no como reglas cerradas del manual original. Si en el futuro se define un Sistema Grafico oficial, este archivo debe actualizarse para reflejarlo.

## Familia geometrica (de donde nace todo grafismo secundario)

El isotipo de Meridiano se construye con tres primitivas: **triangulo** (estructura), **linea** (nivel/base) y **punto** (valor). El de Urbannit con dos: **circulo** (acceso) y **trapecio** (direccion/apertura). Cualquier elemento grafico nuevo — un divisor, un icono, un patron de fondo — deberia poder describirse usando estas mismas primitivas, para que la marca se sienta como un solo sistema incluso en elementos que no son el logo.

## Iconografia (recomendacion)

- Estilo de linea: trazo fino uniforme (peso visual similar al del triangulo del isotipo, ni mas grueso ni mas fino), esquinas y remates redondeados suaves, sin relleno solido salvo para el elemento que se quiera destacar como "punto de valor" (equivalente funcional al punto dorado del isotipo).
- Un set de iconos de servicio (para la seccion de Servicios de la web, brochures, decks) deberia usar circulos de fondo en petroleo profundo con el icono en crema o dorado — replicando la logica de "circulo = contenedor de valor" ya usada en el sitio web de referencia (`assets/meridiano-capital-sitio-web.html`, clase `.circle`).
- Iconografia de Urbannit: mismo criterio de trazo, pero en Ka'a verde/Carbon calido, nunca petroleo/tierra colorada.

## Divisores y estructura

- Lineas divisorias: siempre horizontales finas (1-1.5px), color `Grey calido` con opacidad reducida o el color de linea de referencia `#DAD2C0` — nunca dobles, punteadas decorativas, ni con gradiente.
- Excepcion permitida: linea punteada dorada especificamente para diagramas tecnicos de medicion (ej. zona de proteccion del logo) — ahi la linea punteada es parte del lenguaje de "instrumento de medicion", no decoracion.

## Numeracion y marcadores estructurales — regla de contenido real

Los marcadores numerados (1, 2, 3...) se usan **solo cuando el contenido es una secuencia real** con orden obligatorio (ej. el proceso de 4 pasos: cedula → banco → SA → cierre). No numerar contenido que no tiene orden real (ej. los 5 servicios/unidades de negocio no son una secuencia — se agrupan por "antes/despues de invertir", no por numero). Esta distincion ya se aplico en el sitio web de referencia y debe respetarse en cualquier pieza nueva.

## Supergrafismos / patrones de fondo (recomendacion)

Para fondos de portada o secciones de enfasis (decks, redes, banners), el unico patron de fondo permitido es una variacion sutil del propio isotipo: circulos concentricos finos (evocando lineas de un mapa topografico/meridianos) en baja opacidad sobre fondo petroleo profundo — ya usado en la portada del sitio web y en el deck de inversores. No introducir patrones geometricos no relacionados (no lineas diagonales genericas, no texturas de "ruido" o grano, no formas organicas/fluidas que contradigan la precision geometrica del isotipo).

## Que NO forma parte del sistema grafico

- Gradientes decorativos multicolor (el unico gradiente aceptado es un sutil oscurecimiento tonal dentro de la misma familia de petroleo profundo, como el usado en el hero del sitio web).
- Iconos con relleno de colores multiples o estilo "flat ilustrado" tipo app de consumo masivo.
- Formas redondeadas tipo "burbuja" u organicas que no se deriven de las primitivas geometricas del isotipo.
- Cualquier textura fotografica o de papel/grunge aplicada como fondo decorativo.
